## 实验内容：AI 整页识别（去掉人工分割）

原批量入库是「**人先切题 → AI 逐块识别**」；这里是「**AI 自己切题**」：

```
文档（或**一张图片**） → 转图片 → 整页喂给大模型 → AI 按指定格式输出一页里的 N 道题
                                                    （含「这题要不要配图」+ 那幅图在哪）
   → 结果落进待审文本框 → **配图也已自动裁好** → 老师只看一眼、通过入库
```

**去掉了两步人工**：原来要「人先切题」，现在 AI 自己切；原来要「老师框出那一幅图」，
现在 AI 给出位置、服务端自动裁。老师剩下的事就是**审核**。

**输入也可以直接是一张图片**（png / jpg / jpeg / webp / bmp）：手上只有截图或手机拍的
一道题时，不必先去找工具转 PDF —— 图片被当成**单页文档**，页面渲染、框选、图形探测
这一整套通用。

### 配图为什么能自动裁：模型指路 + 几何定框

不是「让模型把框报准」——实测过，模型报的框**整体偏高约八分之一页**，
只盖住表格下半和图形的顶部。所以分工是：

| 谁 | 干什么 |
|---|---|
| 模型 | 指出「这道题有没有图、大概在这一带」（`figure_box`，归一化 0~1000） |
| **页面几何** | 定**边界**：数字版 PDF 里每个图形元素都带精确坐标（位图 / 矢量图形簇） |
| 服务端 | 把模型的粗框**吸附**到最近的几何候选上，再按这个框裁剪 |

扫描版没有几何可依据（整页就是一张位图）→ 回退用模型估的框，并打 `figure_rough` 标记，
老师一眼能看出「这个框是估的」。

实测（2025 高考全国一卷第 2 页的「图 2」）：模型给的粗框吸附到候选区后，
裁出来**正好是那幅坐标系图**（含坐标轴、箭头、标注文字），一次到位。

几条守卫（都在测试里钉着，改这块先读）：

- 候选区**只收含斜线/曲线的矢量簇** —— 表格框线、分数线全是横竖线，天然排除；
  再加一道「长横竖线交叉＝表格」判据，排掉**单元格里的表头斜线**（实测误报过）
- 整页扫描底图不算图形（占整页 > 55% 的一律排除）
- 「整页只有一处图形」这条兜底**只能发给一道题**：实测踩过 —— 模型说 4 道题有图却
  没给框，兜底把**同一幅图贴给了 4 道题**，比不配图还糟
- 模型说有图却没给出可用的框 → 打 `figure_box_missing`，前台明说「AI 没能定位到，请自己框」；
  **绝不静默变回「不用配图」**
- 提示词明确「仅仅提到几何体名字不算有图」：收紧前模型会把 5 道题里 4 道判成有图，
  收紧后 5/5 判对（只那道真有图的判 true）
- ⚠️ `batch_page.py` **不许 import pymupdf**：全项目只有 `adapters/pdf.py` 能引它
  （AGPL 许可边界）。想算个矩形交并比时最容易顺手破这个界

老师觉得自动裁的图不对时，「调整配图」弹窗会**预填**上次用的框 —— 拖一下边就行，
不必对着整页重画。

换来的是「AI 偶尔把某页切错」，所以两条退路一直留着：

- 「手动分割」页签**保留着**作为回退路径 —— 某页 AI 切坏了，可以只对那一页手动重来
- 待审卡片上没有题块原貌图（整页模式不裁原图），改为显示**来源页缩略图**，方便对照题目在卷面哪儿

### 跨页题怎么办：在待审列表里合并

整理卷面时最常见的毛病是**一道题被页界劈成两半**：上半在第 N 页末尾、下半在第 N+1 页开头，
模型只能当成两道题分别输出。块模式可以在分割处把两段拖到一起，整页模式没有那一步 ——
所以待审列表里补了这套动作（**块模式同样能用**）：

| 动作 | 位置 | 作用 |
|---|---|---|
| **↑ / ↓** | 每张待审卡片右上角 | 和上一条 / 下一条换位。两半不相邻时（AI 偶尔切错顺序）先挪到一起 |
| **并入上一题** | 同上 | 把这条的**题干文本**接到上一条后面，然后删掉这条 |

几条刻意的设计：

- **只合并题干文本**。题型 / 难度 / 知识点 / 标签仍以**上一条**为准 ——
  上下两半各自带的那几项常常不一样（下半句里才看得出是解答题），自动挑一个等于替老师做决定；
  合并后卡片上就能改，老师看一眼比猜准
- **配图不会丢**：本条框了图、上一条没有 → 图迁移过去；**两条都框了 → 直接拒绝**，
  提示先撤掉一张（`figure_image` 只有一列，静默丢一张是不可接受的）
- **合并掉的条目，它独有的截图按引用计数回收**；被合并走的那张不会被误删
  （顺序上是「先 flush 迁移后的引用、再删、最后数引用」，反过来就会把刚迁移的图当孤儿删掉）
- **已入库 / 已驳回的条目不能移动、也不能被跨过去** —— 否则「还没审的那几条」在列表里会被劈成几段
- 合并后 seq 重排成 1..N，编号始终和看到的顺序对得上
- 合并**不可撤销**，所以有确认弹窗；确认前会先把两条的本地编辑都存下来，
  免得刚敲的字被服务端的旧值盖掉

### 怎么用

1. 双击 `启动拾课.bat`（会在 http://127.0.0.1:8010/ 起来）
2. 左边选文档（**或直接上传一张图片**，会自动当 1 页）→ 右栏「识别范围」选**全部页**或**指定页**（一次最多 30 页）
3. 点 **「AI 识别这 N 页」** → 等它跑（每页一次请求，约 5–20 秒；多页并发 3）
4. 在「待审」里逐条核对文本框内容；**配图已经自动裁好了**，只需看一眼对不对 ——
   不对就点「调整配图」，弹窗里预填着上次的框，拖一下边即可
5. 「全部通过」或逐条通过 → 进题库（下游的出卷 / 作业 / 笔记插题一行代码都没改）

### 实现要点（改这块之前先读）

- 核心在 `backend/app/services/batch_page.py`；迁移 `0023_ai_page_batch` 只给 `batch_jobs`
  加了 `ai_mode` / `pages` 两列，**没动 `batch_items`** —— 所以待审 / 配图 / 审核 / 入库下游零改动
- 迁移 `0024_figure_box` 给 `batch_items` 加一列 `figure_box`（自动裁图用的归一化框），
  用途是**让老师能预填着微调**，而不是从零重画
- 接口 `POST /api/batches/ai-pages`（传**页号**，不传题块）；`ai_mode=1` 时任务进度的
  `total` 是**页数**而不是题数（一页可能出 0～N 道题，条目数要识别完才知道）
- 整页 JSON 很长，`max_tokens` 可能截断 → `_iter_json_objects` 逐字符扫描，把前面**完整的**几道题救出来
- **「模型说这页没题」和「解析失败」必须分开**：空白页算正常；解析失败会留一条带 `bad_json` 的
  占位题让老师看见并驳回 —— 宁可让老师驳回，也不让整页静默消失
- 失败页留痕（`_write_page_error`，页号记在 `page_no`），「重跑失败的 N 页」靠它定位；
  ⚠️ 重跑**只删带 error 的占位条目**，已识别 / 已审核的题一条都不碰
- 页是并行识别的，完成顺序随机 → 写库时 `seq = 页号 × 1000 + 页内序号`，末尾 `_renumber()` 收口
- 跨页题在**待审列表**里收口：`POST /api/batches/items/{id}/move?direction=up|down`
  与 `POST /api/batches/items/{id}/merge-up`（见上一节）
- **配图自动裁切**在 `batch_page.py` 的「配图定位」一节；几何候选区探测在
  `adapters/pdf.py` 的 `figure_candidates`（含表格斜线过滤）
- **图片上传**：`documents.py` 的 `PAGE_IMAGE_EXTS` + `_is_paged()`。⚠️ 图片可能带
  `scanned=1`，所以前端判「有没有页面视图」要用 `isPaged`（含图片），
  **不能写 `filetype === '.pdf'`** —— 漏了图片，上传成功但页面视图打不开

#### 关于 `test_render_page.py`（三层防线里最慢也最狠的一层）

「接口全绿但页面白屏」是本项目最贵的一类 bug —— 根因是两个页面都是**零构建手写 HTML**，
根模板走**浏览器解析器**：自定义组件写成 `<x ... />` 时结尾那个 `/` 被忽略 → 当开标签 →
紧跟的 `v-else` 被吞 → Vue compiler-30 → `mount()` 不执行 → 白屏。
**字符串模板语义下复现不出来**，所以三道防线各管一段，别互相替代：

| 防线 | 位置 | 能抓什么 | 代价 |
|---|---|---|---|
| 静态标签配对 + 模拟解析器 | `test_batch_page.py` ⑤ / `test_entry_page.py` | 自闭合、孤儿 `v-else` | 秒级 |
| **jsdom 真实挂载** | `test_render_page.py` → `frontend/render_check.js` | **任何编译期错误**（真实解析器 + 真挂一遍） | 几秒 |
| 肉眼 | 用户 | 布局、配色、交互手感 | —— |

`frontend/render_check.js` 可单独跑（`cd frontend && node render_check.js`），
用 mock 数据把两个页面挂一遍，**不连服务、不碰数据库**。
jsdom 是可选依赖（`npm i jsdom`，或用 `SHIKE_JSDOM_DIR` 指过去），
找不到就打印 SKIP 退出 0 —— 不该因为某台机器没装 jsdom 就把回归弄红。

里面有两个「会让检查**假通过**」的坑，改动时别踩：
`JSDOM.fromFile` 遇**含空格路径**会把基地址解析到盘根（`file:///Q:/vendor/...`），
vendor 全加载不到而 `#app` 里只是未渲染的原始模板（1.8 万字符，长度判据照样「通过」）；
所以①显式给 `url`、②把绝对资源路径改写成相对、③判据必须数**挂载痕迹**
（`.el-button`/`.el-card`/`.el-tag` > 0）并确认 `#app` 里不再残留 `{{ }}` / `v-else-if=`。

个人教师自用的数学题库工具。当前已实现：

- **试卷录入** —— PDF / Word 视觉分割（点两条分界线框选题目，不做文字识别），答案可单独配图；
  已录的题也能事后补答案
- **批量入库** —— 整卷一次性画完分界线 → 并行送 AI 识图（题干 + 题型/难度/知识点/标签）
  → 待审列表逐条核对后通过入库。适合「一次录十套卷」而不是「一次录一道题」。
  **另有实验路线「AI 整页识别」**（本副本新增，见下方专节）：不画分界线，整页交给 AI 自己切题
- **题库与出卷** —— 多条件筛题（体系 / 知识点 / 标签 / 题型 / 难度 / 有无图）、组卷调序、导出 HTML / Word / PDF
- **学生管理** —— 学生档案、能力维度与雷达图
- **课表与课时费** —— 课时排期、课时费结算、家长反馈
- **笔记** —— Markdown 正文 + 公式实时渲染 + Ctrl+V 贴图 + 板书笔画（红黄蓝 / 橡皮 / 粗细 / 撤销）、
  全屏专注模式；可导出 Word / PDF（**公式转成 Word 原生公式**，导出后还能双击编辑）；
  **可直接插入题库里的题**（按关键字 / 标签 / 知识点搜，图会连图存一份），
  同一篇笔记能出**教师版（含答案）/ 学生版（不含答案）**两版
- **课后补充** —— 下课后把这次觉得该练的题与笔记挑进「今天这节课」，下节课一键打印学生版
- **课前备课** —— 上课前给这节课写四段准备（教学目标 / 重点难点 / 教学流程 / 准备材料）、
  挑这节课要用的题与笔记；写完可**一键存成笔记**，也能**从笔记库选取**一篇关联（双向联动）

## 启动方式

**停止：双击 `关闭拾课.bat`**（或直接关掉那个黑窗口，效果一样）。它会认出本项目自己的
服务进程（含 `dev` 热重载模式下的整棵进程树）把端口释放掉，**不会碰你其它的 python 程序**。

- 已经在跑时再双击启动：只开页面，**不会**起第二个服务
- 想放桌面：右键这两个脚本 → 发送到 → 桌面快捷方式
- 换端口：设环境变量 `SHIKE_PORT=8020`（启动与关闭两个脚本给同一个值）；
  不想自动开浏览器：`SHIKE_NO_BROWSER=1`
- 改代码要热重载：`启动拾课.bat dev`（日常使用不必开，重载会在每次保存文件时真重启）

手动启动（等价于脚本里那句）：


## 使用流程

录一道题都是两步：**① 在左侧圈出题目 →「确认题目，去选答案」→ ② 圈出答案 →「保存到题库」**。
答案也可以不圈，直接「跳过答案，直接保存」。左上方两个胶囊可在两步之间来回切。

### 题目的两种形态：文本与图片

一道题可以**同时**存两种形态，预览区里各占一块、各带标签：

- **文本** —— Markdown + `$LaTeX$`。上半是渲染效果、下半是源码框，直接在源码框里改，
  上面立刻跟着变。**入库的是源码本身**，渲染只发生在展示层。
- **图片** —— 框选 / 行标记自动截出的原貌图。图形题、排版复杂的公式题靠它保真。

两者互不覆盖：清除一个不影响另一个。

**还有第三张图：题干配图（`figure_image`）**，别跟上面那张「整道题的原貌图」混为一谈：

| 列 | 是什么 | 谁给 |
|---|---|---|
| `image` | **整块**原貌图（题干、图、排版全在里面） | 分界线选段 / 行标记 / 框选自动出 |
| `answer_image` | 整块答案原貌图 | 同上 |
| `figure_image` | **单独框出来的那一幅图**（题干里那句「如图」指的那张） | 批量审核页手工框（AI 先判有没有） |

为什么非得分出一列：出卷走**文本**形态时，`image` 整张都不印 ——
一句「如图，在四棱锥 P-ABCD 中…」的图就跟着没了，而且**丢了没人知道**。
有了它，文本形态会在题干下面把这幅图补印上；图片形态不印（原貌图里本来就有，印两遍是重复）。
怎么产生它见「批量入库」的第 3 步。

出卷时印哪个，由「**出卷时用**」这项决定（每题一个）：

| 选择 | 行为 |
|---|---|
| 自动（默认） | 有文本用文本、没文本用图 |
| 文本 | 强制文本 |
| 图片 | 强制图 |

**缺哪种形态会自动退回另一种** —— 强制用图但没图、强制用文本但没文本，都不会印出
空白题。出卷页还能整卷再统一改一次（「题目呈现」），整卷选择压过单题偏好。

> ⚠️ 这是一处**有意的行为变化**：以前出卷是「题干文字 + 原貌图」两样都印，
> 现在按上面三选一印一样。老题（`render_prefer='auto'`）里有文本的会改成只印文本 ——
> 如果那份文本是从 PDF 文字层抽的（格式乱），请在出卷页把整卷切成「全部用图片」。

### AI 识别（图片 → Markdown）

「🤖 AI 识别」把**当前那张原貌图**转成可编辑的 Markdown + LaTeX 文本。它认的是图，
所以按钮要先有图才亮 —— 在左侧框出题目/答案后原貌图会自动生成（PDF 分界线选段、
Word 行标记都会出图）。识别结果先落在待确认面板里，核对、改好再「替换」或「追加」，
**绝不直接写入表单**：识别偶尔会看错一个手写字母或正负号，悄悄替你决定了，
错的那一半会一路印到卷子上。

题干和答案各有一条提示词（`vision.PROMPTS` 的 `question` / `answer`）——答案是整段
解题过程，要求**保住换行与步骤顺序**，和「把题干转录成一段」不是一回事。

> 为什么不用 PDF 的文字层？实测过：电子版卷子的文字层对公式是废的 —— 公式被拆成
> 散落的单字符、顺序乱、正负号丢失。所以题干文本一律走视觉识别重建，不做「文本层优先」
> 的正则。分界线选段后仍会先填一份文字层文本垫底，但格式多半会乱，点一下 AI 识别换掉。

### 标签与知识点

录题时可以给题目打**标签**（自由输入、回车确认）与**知识点**（可多选）。两者都会成为出卷页的筛选条件：

- **标签**：多选，**任一命中**。括号里是题数。
- **知识点**：选项把**所有体系**的节点都列在一起（按体系分组），也可以**自己敲**
  —— 目前只有国内高中数学有内置知识树（119 个节点），其他体系请直接手填。
  按知识点筛会连**子节点**一起算，所以选「平面向量」能找到挂在它下面的题。

### 给已录的题补答案（顶部「补答案」模式）

顶部切到「补答案」→ 用关键字搜一道已录的题（或勾「只看还没答案的」）→ 补答案 →「保存答案」。
答案图的三种来源：

1. **📁 从电脑选图片** —— 本机任意图片
2. **🖼 从已有截图选** —— 从库里框选过的截图里挑
3. **上传/切到答案文档后在页面上框选** —— 左边仍然是行标记/框选，圈出来会自动写进**答案图**
   （不会碰到题干与题干图，因为这一步锁定在「第②步」）

保存走 `PATCH`，只改答案相关字段，题干与题干图不受影响。

### Word：行标记（主流程，不做文字识别）

上传 .docx 后，服务端会调用**本机 Word** 把它导出一份 PDF 当页面视图用 —— 首次进入要等几秒，
转换失败（或没装 Word）会自动切到下面的「内容块」模式。

1. 工具选「📝 行标记」：在题目**上方点一下**放起点线，在题目**下方点一下**放终点线
2. 两条线之间（整幅宽，可跨页）就是这道题，自动截成**原貌图**。
   这里刻意**不识别文字** —— 公式、图形、排版全部保真，也不依赖文档有没有文字层
3. 「确认题目，去选答案」→ 第 ② 步在页面上圈出答案图 →「保存到题库」

两条线可以拖动微调、点 × 删除、放完再点即重新标记；勾「吸附到行间空隙」会让线贴到行与行之间。
需要按矩形精确框选时，把工具切到「📷 图片选择」。

> **想要文字时**：框好题后点「🤖 AI 识别（转 LaTeX）」，会把图里的题干与公式转成
> 可编辑文本（公式自动转 `$…$`），核对无误再点「替换 / 追加」。
> 识别结果**不会自动写入表单** —— 它偶尔会看错一个手写字母或正负号，
> 悄悄替老师决定了，那个错误符号会一路印到发给学生的卷子上，而他直到发卷才发现。
> 它会把你框选的这张图发到「设置 → AI 润色」里配置的服务商；
> **不配置就完全不会联网**，截图与手动录题照常用。

### Word：内容块模式（转换不可用时的退路）

1. 顶部切到「内容块」视图，点击一个块设**起点**，再点一个设**终点**
2. 右侧生成预览（KaTeX 渲染 `$...$` 公式），填标签保存

### PDF：页面分割（推荐）

1. 上传 PDF 后自动进入「页面分割」视图，系统按题号**自动放好分界线**（可点「自动识别题号」重新识别）
2. ✂️ 分界线工具：点击页面插入分界线（吸附行间隙；点已有线附近删除；拖动红线微调）
3. 点击段落左侧「页-序号」标签选中该段（**可多选、跨页**），右侧生成题目文本
4. 可点「📷 附加到题目」把选中区域截为高清图随题目入库（公式保真）
5. 📷 框选截图工具：拖矩形罩住整道题，生成图片题（适合图形题/公式密集题）
6. 填题型 / 难度 / 知识点后「确认题目，去选答案」→ 圈答案 → 保存

### 扫描版 PDF：纯截图模式

1. 上传无文字层的扫描版 PDF（手机拍照转的 PDF 也算）不再被拒绝，自动标记「扫描版」
2. 跳过文字解析，直接进入「📷 截图模式」：在页面上拖矩形框住一道题，自动截取 3 倍分辨率高清图入库
3. 想要文字用「🤖 AI 识别（转 LaTeX）」—— **扫描件不需要额外的 OCR 前置**，
   直接送视觉模型即可（实测 DSE 扫描件整页转录全对，且自动忽略了作答横线、
   条形码、页眉页脚，没把空白区当内容吐出来）

### 一张图片就是一份文档

png / jpg / jpeg / webp / bmp 可以直接上传，**当成 1 页的文档**：

- 内部走的是同一条路 —— pymupdf 打开图片就是单页文档，于是页面渲染、框选裁剪、
  图形候选探测**一行都不用改**（`documents.py` 的 `_is_paged()` 把图片和 PDF 一起认）
- 图片没有文字层 → 自动按「扫描版」处理（`scanned=1`，跳过自动铺线，用框选）
- 配图**自动裁切**在图片上没有几何依据（整页就是那一张位图），会退回模型估的框
  并标 `figure_rough` —— 注意核对一下
- 最顺手的用法：手机拍一页卷子 → 传上来 → 用**批量页的「AI 整页识别」**一次切出整页的题

通用：已录入列表支持删除和导出 JSON；顶部可切换历史文档继续分割。

### 批量入库（`/batch.html`，一次切完整卷）

上面那套「一次一道」适合精修。整卷录入用**批量入库页**：左上角「批量入库」进，
或者直接开 http://127.0.0.1:8000/batch.html

流程只有三步，但每步的形状都和逐题录入不同：

1. **一次性分割** —— 选好试卷（或上传新的），在左栏**连着画横线**：
   相邻两线之间自动成为一个题块（不必切一道存一道）。
   也可以切到「📷 框选」按矩形框。工具条：

   | 按钮 | 作用 |
   |---|---|
   | 自动识别题号铺线 | 按 PDF 文字层里的题号锚点一次铺满整卷（扫描件没有文字层，铺不出来，用框选） |
   | 清空分界线 | 全部推倒重来 |
   | 吸附到行间空隙 | **默认关闭**。开启后拖动线才贴到行与行之间（只在附近 14pt 内有空隙时才吸） |

   **画线的两条规矩**（2026-10-05 按反馈改的）：
   - **点哪就是哪** —— 单击只负责「在这里放一条线」，落点就是鼠标位置，不做吸附。
     旧写法是「点在已有线附近就删掉它」，半径取页高的 2.5%（A4 上约 7mm），
     于是想加线常常把刚画好的那条删了。现在**删除只走线上的 ×**。
   - 拖动线可以微调，拖动时会显示精确读数（如 `第 412 / 842 pt`）。

   ⚠️ **自动铺线有上限**：整份识别出超过 40 条疑似题号就**不自动铺**，
   改为提示你手动画或用框选（你自己点按钮时仍可强制铺，会先确认）。
   这道闸是有来由的 —— 一份 46 页的 PPT 型 PDF 曾被自动铺出 **118 条线**
   （页码、参考文献编号、表格里的 `1.6` 都被当成了题号），左栏右栏一起卡死。
   现在判题号更严（要求**行首**是题号、且题号后面不能紧跟数字），
   那份 PDF 的命中数从 295 掉到 1，正常卷子（高考真题、专项卷）不受影响。

   块列表里每一块可以**删掉**、**并入上一页**（上「并上一块」把两块合成一块 ——
   跨页题用这个，服务端会竖拼成一张原貌图）；页顶那块是页眉，删掉后还能「恢复页顶」。

   **每张块卡片上直接显示这一块切出来的样子**（点开可放大）。这是「两条线之间到底
   切成了什么」的唯一凭据 —— 在这之前卡片里只有一句「约 42% 版面」，切歪了、切到页脚了
   都看不出来，得等提交（每次都是一次 AI 调用）才发现。
   缩略图走 `GET /api/documents/{id}/region-image`，由服务端**现渲染、不落盘**
   （`crops/` 是资产目录，每张图都有数据库行引用、删除靠引用计数，预览图落盘就会攒成垃圾），
   倍率 `zoom=1.2` 够看形状、又比印刷分辨率快得多；多段（跨页）会一起带上，服务端照样竖拼。
   图片带 `loading="lazy"`，几十个块不会同时砸向后端。

   ⚠️ **没有分界线的页会整页算一个题块**。多页卷子上这个数会被标出来
   （工具条上的「N 页整页未分割」，块卡片里也逐条注明），提交时再提醒一次 ——
   一份 46 页的 PDF 一条线都不画，就是 46 个题块。

   **大份试卷不会卡**：左栏的页面图**按需加载**（滚动到哪载入哪，旁边写着「已载入 N 页」）。
   46 页的卷子不会一次性解码出几百 MB 位图。切文档时上一份的状态会先清空，
   万一某页读不出来只影响那一页（提示用框选），不会让整页变成空白。
2. **并行识别** —— 右栏选**体系**（整批一个；知识点由 AI 给出），点「识别这 N 块」。
   服务端一次裁出所有块的原貌图（`POST /documents/{id}/batch-crop`，一轮往返裁几十块），
   再**并行**送给视觉模型（默认 3 并发，`SHIKE_BATCH_WORKERS` 可改），每块约 2–5 秒。
   进度条按处理条数走，失败的那几条可以「重跑」。
3. **逐条审核** —— 识别结果**不会直接进题库**，全部落在「待审」列表里：
   题干（上下并排：渲染 / 源码）、题型、难度、知识点、标签、置信度都能改，
   再「通过」或「驳回」。**只有点通过才写进正式题库。**

   审核界面会把可疑的挑出来放大：置信度不是 high 的挂黄色标签，
   被兜底的字段挂 `flag`（见下）。

   **每条审完之后顺手把「题干配图」补上**：每条待审卡下面有一小块配图区。

   1. 勾选框「这题有配图」—— 默认值是**模型判的**（`needs_figure`），
      但**以人勾的为准**。模型判图并不总准：漏判的代价是那幅图永远没人补，
      多判的取消一下就好，所以提示词里明确要求「拿不准时给 `true`」。
   2. 「框选配图」—— 在**原卷整页图**上拖一个矩形，把那幅图框出来
      （图在别的页就翻页；一幅图跨两页就框两段，服务端竖拼成一张）。
      存下来后卡片里直接能看到图，替换会回收旧的那张。
   3. 「撤掉」—— 撤掉后那张图会按引用计数回收（别处没在用就删）。

   **人工兜底的两处提醒**（AI 判错时不让它悄悄过）：
   - 题干里出现了「如图 / 图象 / 图中 / 曲线 / 示意」这类词，而判断是「不需要配图」
     → 黄字提醒你确认（关键词表是**提醒**不是判定：命中不等于有图，没命中也未必无图，
       最终以人勾的为准。表在 `app/taxonomy.py` 的 `FIGURE_KEYWORDS`，由接口下发，前端不写死）
   - 模型**没给出**这个判断（字段缺失 / 空串 / 说了句看不懂的话）→ 打 `figure_unknown`
     flag 并提醒「请自行确认」。⚠️ 这种情况**不能当「否」处理** —— 当成 `false` 会让本该
       复核的条目静默过审，而漏掉的图没有任何后续环节会发现。

   通过时 `figure_image` 会跟着题目一起进题库（单独一列，与整块原貌图分开存）。

- **题型 / 难度**的下拉选项由 `GET /api/batch/options` 下发，取值唯一出处是
  `app/taxonomy.py` —— 同一份取值同时写在**提示词**里（让模型只能从里面选）与校验里，
  前端再写一份就会出现「下拉里没有的值」这种不报错的错位
- **知识点**由模型给名字，服务端去所选体系的知识树里**模糊匹配**（`services/knowledge.py`）：
  完全同名 → 归一化后同名 → 归一化后互相包含（取名字更具体的那个）。
  匹配不上就原样存老师/模型的措辞并留空 `node_id`（不猜 —— 猜错会把题挂到别的考点上）。
  ⚠️ **模糊匹配只给批量开**：手动录题时老师是从下拉里挑的，替他做主反而更糟
- 删除任务**不会**带走已入库的题目，截图按引用计数回收
- 「重跑失败项」只重跑真失败的那些，成功的不会白白再烧一遍 API

#### 对大模型返回值的限制（这批功能的关键）

模型返回的是一段自由文本，脏数据是**静默**流进待审列表的 —— 接口全返 200。
所以返回值限制做了三层，缺一层都会漏：

| 层 | 做法 |
|---|---|
| ① 提示词 | 写死**九个**字段、枚举取值原样列出、标签 0–4 个每个 2–6 字、**只输出一个 JSON 对象**、给输出示例 |
| ② 请求参数 | `temperature=0` + `response_format={"type":"json_object"}`；服务商不认这个参数就**自动去掉重试一次**（408/400 降级） |
| ③ 后端解析 | 剥代码围栏 → 取第一个 `{` 到最后一个 `}` → 修尾随逗号；还是解不出就给一份**永远可入库**的默认值 + `flags` |

`flags` 取值：`bad_json` / `json_repaired` / `empty_stem` / `qtype_fallback` /
`difficulty_fallback` / `confidence_fallback` / `figure_unknown`。
审核界面上它们会被翻成人话的标签，老师一眼能看出「这条是兜底的，得自己看」。

> **布尔字段的写法比字符串更容易出岔子**：`needs_figure` 要求写 `true`/`false`
> 而不是 `"true"`，但模型仍会给出 `是`、`需要`、`1`、`y` 这类写法，甚至整段不给。
> `_as_bool()` 因此返回**三态**：`True` / `False` / `None`。
> ⚠️ `None` **不等于** `False` —— 空串、`null`、字段缺失、说了句看不懂的话，
> 全都算「没判出来」，落 `figure_unknown` 提醒人工看；当成 `False` 会让该复核的条目
> 静默过审（见上一节）。**空串刻意不在 `_FALSE_WORDS` 里**，这是故意的取舍。

> `parse_fields()` **永不抛异常** —— 一条脏结果不该让整批任务失败，
> 也不该让它悄悄写进题库；正确做法是标成异常项放进待审，由人决定。
>
> ⚠️ 提示词里的 LaTeX 反斜杠必须写**双份**（`"\\frac"`）。写单份会被 Python 吃掉
> （`\f` → 换页符、`\t` → 制表符），而模型照样有输出，只是公式规范变差 ——
> 从任何日志上都看不出来。`test_batch_fields.py` 断言整份提示词里没有控制字符。

#### 并发与数据库

识别是并行的，**写库是串行的**：工作线程只做「读图 → 调模型 → 解析」，不碰数据库会话；
结果汇总回主线程/独立短事务落盘。SQLite 是单写者，多个线程同时写会撞 `database is locked`。
单独一条最多 90 秒（`PER_ITEM_TIMEOUT`），失败自动重试 1 次。

#### 出问题怎么查

批量页的失败方式很分散（模型、网络、Word、PDF、浏览器各自有一套），所以做了三件事让人能定位：

- **服务日志落盘**：`backend/data/logs/shike.log`（2 MB 轮转，留最近 3 份）。
  服务窗口里一闪而过的报错这里都有，未处理异常还带请求路径与调用栈。
  ⚠️ 以前没有这个文件 —— 用户说「弹了个报错，然后程序就访问不了了」时，只能靠猜。
- **未处理异常不再只说 `Internal Server Error`**：`main.py` 挂了兜底处理器，
  返回体里带异常类型与消息，前端直接把原因弹出来（`HTTPException` 仍走原来的链路）。
- **前端每步各自兜错**：切文档失败只影响左栏，弹一次说明原因并把状态清空，
  不会留下「新文档配旧页面数据」的半截状态（那种状态会让渲染函数抛异常 → 整页点不动）。
  渲染或事件里抛异常由 `app.config.errorHandler` 统一记一笔，页面其余部分继续可用。

一条容易踩的经验：`GET /api/documents/{id}/pages` 对 Word 文档会**同步调用 Word** 做转换。
批量页刻意不触发它 —— 没有页面图的 Word 文档会直接告诉你「先去逐题录入页生成」，
免得点下去像没反应（那一步可能几十秒）。

### 删除一份文档

文档卡片右上角的「删除此文档」——上传错了、或者这份卷子录完了不再需要，用它清掉。

确认框会先把**账摊开**（数字都是服务端实时统计的，不在前端估算）：

- 会删掉哪些文件：试卷原件、Word 转换件、页面图缓存，各占多大
- 这份文档下已经录了几道题 → **默认保留**，要连题一起删得自己勾那个勾选框

三条设计上的取舍：

- **删文档 ≠ 删题**。题目是独立资产（有自己的文本、截图、可能已经出过卷），
  顺手带走属于「用户没说过的事」，所以默认不勾、接口默认 `with_questions=false`。
  保留时会把题的 `document_id` 清空，来源名 `doc_filename` 留着（题库里还能看出它出自哪份卷子）。
- **截图按引用计数回收**：同一张图可能被别的题当答案图用着，只删没人再引用的那些
  （与 `delete_question` 共用一份判断，见 `services/crops.py`）。
- 删记录前**自动备份一次数据库**（理由：文件删了回不来，至少让「当时哪几道题挂在它下面」有据可查）。

对应接口：`GET /api/documents/{id}/delete-impact`（纯读取，可反复调）、
`DELETE /api/documents/{id}?with_questions=false`。

## 接口一览（本批新增）

| 方法 | 路径 | 作用 |
|---|---|---|
| GET | `/api/batch/options` | 题型 / 难度 / 置信度 / 标签限制 / 并发数 / 配图关键词表 |
| GET | `/api/documents/{id}/region-image?spec=&zoom=` | **只读**预览某块切出来的样子（现渲染、不落盘，多段竖拼）。`spec` 形如 `1:40,90,550,300`，跨页用 `;` 连 |
| POST | `/api/documents/{id}/batch-crop` | 一次裁多块（含跨页竖拼），逐块容错 |
| POST | `/api/batches/items/{id}/figure-crop` | 框出题干配图（多段竖拼；替换时回收旧图，顺手把 `needs_figure` 置真） |
| POST | `/api/batches` | 建任务（`start=false` 只建不跑，测试用） |
| GET | `/api/batches` | 历史任务列表 |
| GET / DELETE | `/api/batches/{id}` | 任务详情 / 删任务（条目连带删，已入库题目不动） |
| GET | `/api/batches/{id}/items?status=` | 条目列表，可按 `pending`/`approved`/`rejected` 过滤 |
| PATCH | `/api/batches/items/{id}` | 审核时改字段（只改传上来的那些，枚举照校验）。`needs_figure` 是人工勾的那个；`figure_image=""` 撤掉配图并按引用计数回收 |
| POST | `/api/batches/items/{id}/approve` `\|reject` `\|reset` | 通过入库 / 驳回 / 退回待审 |
| POST | `/api/batches/{id}/rerun?only_failed=true` | 重跑（默认只重跑失败项） |

## 已知限制（后续迭代）

- **批量入库只识别题干与元数据，不识别答案**（分了两步走，先跑通「题干 + 题型/难度/知识点/标签」）。
  答案仍走逐题录入页的第 ② 步，或事后「补答案」模式
- **框选配图要有页面视图才点得动** —— 它是从原卷页面上框的。没有页面图的 Word 文档
  会提示「先去逐题录入页生成页面图」；这一步**刻意不在这条请求里触发 Word 转换**
  （那可能卡几十秒，看着像点不动）。上传的 PDF 一直有页面图，不受影响
- **批量任务没有进度推送**，前端 1.5 秒轮询一次任务状态；服务进程如果在识别中途重启，
  那一批会停在 `running`（条目状态不像库那样会被写坏，但需要手动重跑）
- **导出 PDF 是断点**：`paper_export.build_pdf` 只走 `insert_textbox` 纯文本，
  LaTeX 公式会印成 `$…$` 原文。HTML / Word 两条路是好的（Word 走 OMML 真公式）。
  出 PDF 请先用 Word 导出，或等 P7
- **内置卷种样式的取值升级没有正式通道**：`ensure_paper_templates` 按 `name` 判重、
  只补不覆盖，所以改了内置模版的默认值不会自动同步到已有库，得按 `code` 手动同步
- `frontend/entry.html` 的录题表单里仍有一份题型/难度取值的**自己的拷贝**
  （新页面 `batch.html` 是走 `/api/batch/options` 的）。改 `app/taxonomy.py` 时记得两边一起改
- **A-Level 卷种样式是照英文卷通行结构写的空壳**，未经真题校准；手写体 / 劣质扫描件也还没有样本
- PDF 文字抽取对复杂数学公式保真度有限 → 用「附加原貌截图」兜底，人工改 LaTeX
- 早期上传的旧文档没有保留原文件，页面分割会提示重新上传
- docx 中表格与正文的先后顺序不保持（表格追加在末尾）
- `.doc` 旧格式不支持，需另存为 `.docx`
