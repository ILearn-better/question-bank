# 专属题库工具

个人教师自用的数学题库工具，当前已实现：**PDF 视觉分割（点击分界线 + 框选截图）** 与 **Word 内容块分割录入**。

> 详细技术选型、数据库设计、OCR 管线与开发计划见 [docs/技术方案设计.md](docs/技术方案设计.md)

## 启动方式

```bash
cd question-bank/backend
pip install -r requirements.txt
python -m uvicorn main:app --host 127.0.0.1 --port 8000 --reload
```

浏览器打开 http://127.0.0.1:8000

## 数据说明

- 所有题目、文档记录存在 `backend/app.db`（SQLite），重要题库可定期备份此文件
- 上传的原文件、页面渲染缓存、裁剪截图存在 `backend/uploads/`
- 知识点树在 `data/math-knowledge-tree.json`，接口为 `GET /api/tree`

## 使用流程

### PDF：页面分割（推荐）

1. 上传 PDF 后自动进入「页面分割」视图，系统按题号**自动放好分界线**（可点「自动识别题号」重新识别）
2. ✂️ 分界线工具：点击页面插入分界线（吸附行间隙；点已有线附近删除；拖动红线微调）
3. 点击段落左侧「页-序号」标签选中该段（**可多选、跨页**），右侧生成题目文本
4. 可点「📷 附加原貌截图」把选中区域截为高清图随题目入库（公式保真）
5. 📷 框选截图工具：拖矩形罩住整道题，生成图片题（适合图形题/公式密集题）
6. 填写题型/难度/知识点/答案/解析后保存

### Word：内容块分割

1. 上传 .docx 后进入「内容块」视图，点击一个块设**起点**，再点一个设**终点**
2. 右侧生成预览（KaTeX 渲染 `$...$` 公式），填标签保存

### 扫描版 PDF：纯截图模式

1. 上传无文字层的扫描版 PDF（手机拍照转的 PDF 也算）不再被拒绝，自动标记「扫描版」
2. 跳过文字解析，直接进入「📷 截图模式」：在页面上拖矩形框住一道题，自动截取 3 倍分辨率高清图入库
3. 待 OCR 通道接入后，扫描版将支持自动识别文字

通用：已录入列表支持删除和导出 JSON；顶部可切换历史文档继续分割。

## 已知限制（后续迭代）

- PDF 文字抽取对复杂数学公式保真度有限 → 用「附加原貌截图」兜底，人工改 LaTeX
- 早期上传的旧文档没有保留原文件，页面分割会提示重新上传
- 扫描版 PDF 暂无 OCR，只能截图录入（文字自动识别待 V1.5）
- docx 中表格与正文的先后顺序不保持（表格追加在末尾）
- `.doc` 旧格式不支持，需另存为 `.docx`
