## 0. 一句话结论

**作业和课堂是两件事，别塞进同一套维度里。** 课堂评的是「这节课他表现如何」，
作业评的是「他自己独立做题的质量如何」——后者才是家长真正焦虑的东西，也是老师最难自证的。

技术上它比看起来便宜：**上传走现成的文件管线，打分照抄能力评分那套，归档复用现有的
「学生 / 上课日期」目录**。真正需要先想清楚的是三件事：

1. **维度选哪几个**（老师会不会嫌麻烦，直接决定这个功能会不会被用起来）；
2. **「没交」怎么记**（用 0 分记会把雷达图和平均分一起带偏）；
3. **AI 不许给分**（下面的「边界」一节 —— 这是本方案最容易做错的地方）。

## 1. 已经可以复用的东西（比想象中多）

| 需要的能力 | 现在已有的 | 复用方式 |
|---|---|---|
| 上传讲义/试卷/照片 | `lesson_files` + `file_text`（PDF/Word/PPT/图片抽文字）+ 魔数校验 ✅ | 加一个 `role` 列区分「上课材料 / 作业」即可，其余不动 |
| 按「学生 / 日期」归档 | `storage` 的 `students/u<id>_<姓名>/<上课日期>/` ✅ | 作业就放同一格：那节课的讲义、作业、反馈 txt 本来就该在一起 |
| 1-5 星打分 | `ability_dims` + `ability_scores`（维度可自定义、1-5、可只打几项）✅ | 照这套做作业的维度与评分，交互与校验都能沿用 |
| 雷达图 / 变化趋势 | `feedback_export.build_radar_png`、学生页雷达 + 「本次 vs 上次」✅ | 同一套画法，换一组维度即可 |
| 删课时/删学生的清理 | `collect_lesson_assets`、`remove_student_dir`、引用计数 ✅ | 作业文件与作业评分必须挂进同一套清理，否则又会漏出孤儿 |

**结论（🤔）：不需要新的上传通道、不需要新的归档布局。** 需要新增的是「作业」这个实体
和它自己的维度表 —— 因为作业有课堂没有的东西：**交没交、什么时候交的、哪一天布置的**。

## 2. 建议的维度（提案，需确认）

选维度的标准是我自己定的三条：**老师一眼能判断**（不用翻旧记录）、**不同维度之间不重复**、
**能指导下一步动作**（打完分知道该让他干什么）。太抽象的（如「思维能力」）不要，
一节课作业看不出结论，打完分也不知道该做什么。

| 维度 | 看什么 | 为什么值得单独一栏 |
|---|---|---|
| **完成度** | 做没做全、有没有漏题/大段空白 | 最高频、最客观的观察。漏做和做错是两种问题，补救方式完全不同 |
| **正确率** | 结果对错（可与题量一起看） | 最直观，也是家长最先问的 |
| **过程与规范** | 步骤是否完整、书写与卷面 | 数学上「答案对而过程跳步」是 DSE/中高考的**真实失分点**，必须单独看见 |
| **独立完成** | 是否自己做的（与答案一字不差、步骤跳跃但全对、课上同类题不会） | 老师最容易忽略、但直接决定「正确率」这一栏可不可信 |
| **订正与复盘** | 上次错题改没改、是否只改答案不写过程 | 唯一一个**跨次**才看得出效果的维度，也是本系统「按薄弱点出题」的入口 |

**关于「按时交」：建议不做成维度，做成状态。** 🤔 理由是性质不同 ——
按时/迟交/未交是**事实**，完成度/规范是**判断**。事实用字段记（可统计、可用于筛「谁老不交」），
判断用 1-5 星打。两者混在一张雷达图上，会让人分不清哪个是客观的。

**规模建议：5 项、1-5 星、允许只打其中几项**（与能力评分完全一致）。
一口气 8 项以上老师就会跳着打，数据反而更差。

## 3. 「没交作业」必须是一等状态，不是 0 分

这是我认为最容易做错、后果最难发现的一处 —— **用 0 分记「没交」，雷达图和趋势会一起失真**：
一次没交就把平均值拽下去，看起来像「这孩子两周内退步了」，而事实是他那天生病没写。
更糟的是这数据会长久留在 `ability_scores` 里影响「上次 vs 本次」的对比。

所以：

- 作业的**状态**：`assigned`（已布置）/ `submitted`（已交）/ `late`（迟交）/ `missing`（未交）
- **只有 `submitted` / `late` 才打分**；`missing` 不计入任何平均与雷达
- 界面上「未交」要显眼（家长沟通里这是必须提的事），但**不假装它是个低分**

## 4. 数据结构草图（照现有风格，迁移应为 `0013`）

```text
homeworks                    新增
  id / owner_id / student_id / lesson_id(可空) / date
  title            如「9.1 特殊角三角比 课后练习」
  status           assigned / submitted / late / missing
  note             老师的批改备注（自由文本）
  created_at

homework_dims                新增（对标 ability_dims）
  id / owner_id / name / curriculum_id / sort_order / active
  预置 5 条：完成度 / 正确率 / 过程与规范 / 独立完成 / 订正与复盘
  ⚠️ 照 ability_dims 的做法 —— 在**迁移里 `op.bulk_insert` 一次性写入**（0004 就是这么种下
     那 5 个课堂维度的）✅，而不要用 feedback_templates 那种「每次启动按名字补缺」：
     维度是老师可改可停用的，补缺式的种子会把他删掉的维度又装回来

homework_scores              新增（对标 ability_scores）
  id / owner_id / homework_id / student_id / dim_id / score(1-5) / created_at
  只存真正打过的分（缺项 = 没这张行，**不要存 0** —— 与现有 ability_scores 一致：可只打几项）✅

lesson_files                 加一列
  role: 'material' | 'homework'（默认 material）
  → 上传、抽文字、归档、清理全部沿用现有管线，一行都不改
```

为什么给作业单独建表、而不是往 `ability_scores` 上加个 `kind` 列：那个做法能让趋势/导出代码
全部复用，但**每一条现有查询都必须记得加 `kind='class'` 过滤**，漏一处就是课堂分和作业分
混进同一张雷达图 —— 这种错很隐蔽，而收益只是少写几张表的查询。🤔 我倾向分开。

## 5. 老师在哪里打分

建议**就在课后反馈弹窗里**，新开一块可折叠的「本次作业」，而不是单独一个页面：
老师本来就是上完课顺手翻他作业、顺手写反馈的，为打分再跳一个页面，大概率就不打了。

区块内容：上传作业照片/文件 → 选状态（已交/迟交/未交）→ 五个维度点星 → 批改备注。
「未交」时自动把打分隐藏（没有作业可评）。

学生页加一个切换：「课堂表现 / 作业质量」两张雷达图（或一张图两条线）。
🤔 两条线放在一张图上更直观，但两套维度不同，硬画在一张图上会让人误读，所以建议**分开两张**。

---

## 6. 边界：AI 不许给作业打分

这条是硬约束，直接沿用现有提示词第 7 条的思路 ✅：

> 材料只能用来核实「讲了什么/布置了什么」，**绝不能从材料推断学生表现**。

作业场景下要更严格，因为「作业照片」看起来最像「可以据此评价孩子」。明确写清：

- **打分是老师的事**。AI 最多做两件事：① 把作业里的字读出来（`file_text` 已经在做）
  ② 整理老师的批改备注成通顺的话。
- **绝不生成「完成度 3 分」这类建议分数。** 图片作业连题目都读不全，
  凭笔迹/涂改推断「粗心」是伪科学，而且会顺着老师的措辞偏好编，一旦被当真就是误导家长。
- 若以后要做「批改建议」，必须是**显式触发**、且界面写清「仅供参考、不自动写库」。

## 7. 与已有两条线的接口

- **家长报告（现在的导出）**：作业维度进不进 doc，是导出时的选项，不要默认塞进去 ——
  「作业」和「课堂」一起念给家长听，重点会散。🤔 建议家长稿里只在「作业情况」栏目里点名
  1-2 个维度 + 状态，完整雷达留在系统里。
- **学生记忆 / 学生 Agent（见 `学生记忆与Agent方案.md`）**：那份文档里说
  「`ability_scores` 是唯一可量化的趋势数据」。**作业评分补上了第二类趋势数据，而且更接近
  家长关心的「他自己会不会做」**。将来做画像时，「作业 vs 课堂」的**差距**本身就是一条
  高价值信息（课堂会、作业不会 → 依赖提示；课堂不会、作业全对 → 值得单独问一句）。
- **题库 / 知识树**：错题如果能标知识点，就能接上「按薄弱点出题」那条杀手锏。
  🤔 这是这个功能最有价值的延伸，但属于第二阶段，不要一上来就做。

## 8. 分期建议（未排期）

- **A（最小可用）**：作业上传（复用文件管线）+ 状态 + 5 维打分 + 学生页作业雷达。
  这一期就能交付「家长问起来有据可依」。
- **B**：作业趋势表（每次的 5 维变化）、把作业状态纳入「待办」提醒（谁老不交）。
- **C**：错题标知识点 → 接题库按薄弱点出题；作业数据进学生画像。
