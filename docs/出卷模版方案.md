# 出卷模版方案（想法记录）

> 记录时间：2026-09-30。**状态：只是想法，未排期、未实施**。
> 用户原话：「在出卷模块做出卷模版，可以选择不同模版出卷，例如，高考，中考，dse考试，普通测试等，可自主扩展」。
> 下面把**已核实的代码事实**与**判断/待确认**分开写，免得将来把猜测当结论。

---

## 0. 一句话

「模版」有两种读法，工作量差一个量级：**① 卷面样式预设（轻） ② 考试结构（重）**。
名字本身两张都沾（「高考卷」既指排版也指结构），所以**推进前必须先定这个**，其余都是细节。

## 1. 两种读法

**A. 卷面样式预设**：一组出卷开关 + 排版参数的预设。
覆盖的是高频且真实的差异，例如：
- 课堂小测：不要姓名栏、标题型难度、**不要答案页**
- 正式测验：留姓名/班级/日期栏、答案另起一页
- DSE 卷：抬头格式、留答题空白（老师再手写批注）
- 打印给学生 vs 打印给自己（教师版/学生版，已有）

**B. 考试结构**：题型/题量/分值/时长/知识点分布的结构描述，甚至「按结构凑题」。
- 需要的新东西：分值、分区标题、总分与时长 → 见第 4 节
- ⚠️ **与既有红线的冲突点**：本项目明确过「**不做推荐算法 / 自动挑题 / 自动排序，内容由老师挑**」
  （写在 [学生画像与推题出卷方案.md](学生画像与推题出卷方案.md) 第 5 节）。
  B 一旦做成「自动凑题」就跨过这条线。
- 可以退一步、不越线的做法：模版只给**结构提示**——
  「本卷应有 8 选择 + 4 填空 + 6 解答」，界面上显示已选数量与缺口，
  **挑哪道题仍然由老师决定**。这个形态更贴合「老师自己组卷」的实际习惯。

## 2. 现状（已核实的代码事实，2026-09-30 对着代码看）

- 出卷页 `frontend/src/views/Papers.js`：筛题 → 已选（**顺序即卷面顺序**）→ 卷面选项 → 预览/打印/导出。
  卷面选项现在就是 **4 个芯片开关**：学生版/教师版、答案带解析、标注题型·难度·标签、留姓名日期栏，加上一个卷子标题。
- 后端 `GET /api/papers/export`（`routers/papers.py`）参数：
  `ids` / `format` / `title` / `show_answer` / `show_analysis` / `show_tags` / `show_meta`。
- `services/paper_export.py`：`build_html` / `build_docx` / `build_pdf` **三个渲染器共用同一个 `opts` dict**。
  → 这就是「模版」最自然的落点：**模版 = 一组 opts 预设**，渲染层不用认识「模版」这个概念。
  页面尺寸与页边距目前是写死的（`A4_W/A4_H = 595.28×841.89`、`MARGIN = 50`）。
- 题库有 `qtype` / `difficulty` / `knowledge_points` / `tags`（结构模版能用上），
  **没有分值字段** —— 分值只能靠模版给，不是靠题目自带。
- 项目里已有两处「模版」先例，做出来的行为用户已经被教过一次：
  `feedback_templates`（录反馈用的快捷短语 + 骨架）与 `feedback_doc_templates`（整篇结构与文风）。
  两者形状统一：`name` + 内容 + `is_builtin` + `sort_order`；
  种子**只按名字补缺、绝不覆盖用户改过的**；内置可改文案、**不可删**（删了下次种子又建回来，反而迷惑）。

## 3. 若确认做 A（建议的第一步）

- 新表 `paper_templates`：`name` + `opts`(JSON) + `is_builtin` + `sort_order`（迁移号届时顺延）。
- 内置几套（名字先占住，参数按用户实际用法再定）：
  普通测试（= 现在的默认）、课堂小测、正式测验、高考 / 中考 / DSE（后三个先做成空壳）。
- 接口 `GET/POST/PATCH/DELETE /api/paper-templates`。
  **导出接口保持不变**：前端把模版展开成现在那几个参数即可 —— 服务端不需要知道「模版」这回事，
  于是「不选模版」＝现在的行为，向后兼容，也少一层耦合。
- 出卷页「卷面选项」上面加一个**模版下拉**（含「存为模版」/「管理」）：
  选模版 = 一键填好那几个开关，**填完仍可手动微调**；微调后提示「已不同于「高考」模版」。
- 「可自主扩展」的形态 = 复制一套内置的改一个 / 新建空白；管理入口就放在**出卷页**
  （在用它地方管它，不去设置页绕一圈）。

## 4. 若要做 B（结构模版）需要先有的东西

- **分值**：题级 `score`，或模版级「每题多少分」。现在都没有。
- **分区**：高考「第 Ⅰ 卷（选择题）/ 第 Ⅱ 卷」、DSE「Section A / B」——
  题库里一道题就是一条记录，**没有「分区」概念**，只能由模版定义分区 + 题号重排。
- **大题含小题**：题库也没有「第 21 题 (1)(2)」这种层级。真卷里很常见，缺它结构模版就不完整。
- **总分与时长**：至少抬头要能写「本卷满分 150 分，时间 120 分钟」（这个纯显示，最便宜）。
- 这些凑齐才谈得上「按结构凑题」，而凑题本身又回到第 1 节的红线问题。

## 5. 顺手值得一起想的（都属于 A 的延伸）

- 排版参数化：页边距、正文字号、题间距、页脚「第 x 页 / 共 y 页」、答案页是否另起一页。
- 留白：给手写/批注留空间（现在题与题之间是自然间距）。
- 题干图缩放上限（现在图片按原始宽度插入，宽图可能超出打印范围）。
- 双栏排版（语文/英语卷常见）—— 数学卷少见，**建议不做**。

## 6. 不做（先说清，免得反复讨论）

- **不做「按考试大纲自动组卷」**：那是替老师决定考什么。
- **不做自动分栏/断页优化**：现在 Word/PDF 已经够用，收益不抵复杂度。
- **不做在线答题/自动批改**：越界，与实际形态（打印出来线下发）不符。

## 7. 待确认（推进前先定，按重要性排）

1. 🔴 **要做 A（卷面样式预设）还是 B（考试结构）？** —— 先定这个，其余都是细节。
2. 模版要不要带「分区标题」与「分值」？（哪怕只用于抬头显示）
3. 内置哪几套、各叫什么（高考 / 中考 / DSE / 普通测试 / 课堂小测 …）。
4. 模版是「一键填空、可再改」还是「选了就锁」？（建议前者）
5. 管理入口放出卷页还是设置页？（建议出卷页）
