# 把现成文档导入成笔记（Word / PDF / HTML / 文本 / PPT）

> 需求提出：2026-09-28。**状态：已实现**。用户原话：「我可以传 word 文档或者 html 或者 pdf 作为笔记。」

## 0. 一句话结论

笔记页左栏的 **「导入文档」** 按钮：选一个 Word / PDF / HTML / 文本文件，
它就变成一篇笔记 —— **正文转成 Markdown，原件一起存进笔记，失真与警告写在正文开头**。

```
笔记页 → 导入文档 → 选文件 → 笔记自动打开（标题取自文件名，落在你选中的目录里）
```

## 1. 三条原则

### 1.1 转的是**结构**，不是纯文字

`services/file_text.py` 抽文字是**给 AI 看的**（连续文字就够）；这里转出来是**给人看的**，
所以标题、加粗、列表、表格、图片位置都要留住 —— 打开得像一份笔记，而不是一坨文字。

| 格式 | 怎么转 | 大概会失真在哪儿 |
|---|---|---|
| `.docx` | 走 OOXML：标题样式→`#`、`w:b/i`→`**`/`*`、`w:numPr`+`numbering.xml`→有序/无序列表、`w:tbl`→Markdown 表格、内嵌图**就地**插入 | **公式只留文字**（OMML→LaTeX 的反向 XSLT 没做）；文本框位置会变成普通段落 |
| `.doc/.rtf` | 先交给本机 Word 转 PDF，再按下一条走 | 同 PDF |
| `.pdf` | 按页抽文字，多页时给 `## 第 N 页`（左侧「目录」面板能当导航用） | 分栏/页眉页脚还原不了 |
| `.pdf`（扫描件） | **没有文字层时按页转成图片**塞进笔记（上限 40 页） | 不能搜索、不能复制文字；但能直接用画笔标注 |
| `.html/.htm` | 自己写的标签→Markdown 子集（标题/段落/加粗/斜体/列表/表格/引用/代码/链接） | 外链图片取不回来（本机不联网），保留成链接 + 提示；`data:` 内嵌图会**存进笔记** |
| `.pptx/.ppt` | 按页取文字 + `## 第 N 页` | 纯图页没有文字 |
| `.txt/.md` | 原样收下（`.md` 不再转一遍） | 无 |

**扫描版 PDF 不是失败** —— 这是这个项目反复强调的一条（见 `file_text.py` 开头）：
它只是「没有文字层」，按页存成图片正是老师要的（可以在上面写字）。
真正该报错的是**内容确实是空的**：空文件、纯图 Word、没有内容的 HTML → 422，并说清能怎么办。

### 1.2 原件一定一起存下来

转出来的 Markdown 是「能读、能编辑、能喂 AI」的那部分；**原件是「一定没丢」的那部分**。
所以原文件会被存进笔记的资源目录，并在正文开头给一条下载链接：

```markdown
> 从「高二数学专项测试卷.docx」导入（Word，902 字）
> 原始文件：[高二数学专项测试卷.docx](/api/notes/files/nb_e8fa21f41ce9.docx)
```

它和配图走同一套引用计数：**删掉这篇笔记，原件与配图一起清掉**（接口回
`images_removed`）。

### 1.3 失真写在笔记开头，不藏着

`doc_to_note.header_block()` 会把「从哪来、原件在哪、哪里不准」写成一段引用块放在正文最前。
理由很实际：过两天再打开这篇笔记，得能看出它是导入的、以及哪句话不能全信。
嫌碍事直接删掉那段引用块即可。

## 2. 接口与入口

```
POST /api/notes/import-doc?folder_id=<可选>      multipart: file
→ {id, title, folder_id, chars, images, pages?, original, kind_cn, warnings[]}
```

前端：笔记页左栏「导入文档」（第二行，和「备份 / 迁移」放一起 —— 这两件事都不常做）。
导入完直接把笔记打开，让人第一眼看到结果，而不是先看一堆说明。

## 3. 踩过的三个坑（都值得记）

1. **`.docx` 的 zip 句柄没关 → Windows 上临时目录都删不掉** → 收尾时报
   `WinError 32`，整个导入接口 500。Linux 上根本不会出现，所以更该写死在注释里：
   读写文档一律 `with zipfile.ZipFile(...)`；临时目录用
   `TemporaryDirectory(ignore_cleanup_errors=True)` 兜底 —— 留个临时残渣远好过丢掉一次成功的导入。
2. **HTML 文本节点不能无脑补尾空格**：`<strong>相加</strong>` 会变成 `**相加 **`，
   而 Markdown 的结束标记前面**不允许有空格**，加粗就默默失效了。
   正确做法是只把连续空白压成一个空格；另外空标签（`<strong></strong>`）要让开标记能撤回，
   否则会留下 `****`。
3. **空文件不能静默变成一篇「只有来源说明」的空笔记** —— 那比失败更让人糊涂。

## 4. 没做的

- **Word 公式（OMML）→ LaTeX**：需要 Office 的反向 XSLT（`OMML2MML.XSL` → MathML → LaTeX），
  是另一个量级的活。现在只留公式里的文字，并在笔记开头说明。
- **PDF 版面还原**（分栏、页眉页脚、表格线）：抽文字做不到，要真还原得上版面识别（见 `版面识别方案调研.md`）。
- **HTML 外链图片下载**：本机不联网是硬约束，只能提示用户手动截图。
- **按目录批量导入**（一次拖一个文件夹进来）：现在一次一个文件。
- **导入时自动挂到知识点**：和笔记树的定位一致 —— 笔记目录是老师自己的整理习惯，不自动跟随大纲。
